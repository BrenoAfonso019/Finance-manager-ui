# 💰 Finance Manager - Web Application

Interface moderna e intuitiva para controle financeiro pessoal, desenvolvida com foco em usabilidade, design minimalista e clareza de dados.

## 🚀 Tecnologias Utilizadas
- **React** (v19)
- **TypeScript**
- **Tailwind CSS**
- **Vite**
- **Lucide React** (Ícones)

## ✨ Funcionalidades
- **Dashboard Geral:** Indicadores de saldo total, receitas, despesas e distribuição por categoria.
- **Previsão & Metas:** Card de previsão de fluxo de caixa e simulação interativa de metas de economia.
- **Gestão Orçamentária:** Acompanhamento visual de limites de gastos por categoria com alertas de teto.
- **Filtros e Relatórios:** Visualização dinâmica de períodos e resumo de transações financeiras.
